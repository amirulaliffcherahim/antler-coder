## [Unreleased]

### Added

- Core IDE shell with file explorer, CodeMirror 6 editor, and xterm.js terminal tabs
- BYOA (Bring Your Own Agent) system with auto-discovery of CLI agents
- Multi-tab floating agent popup terminal using portable-pty
- WSL integration: agent discovery and spawning inside WSL distros
- BYOK (Bring Your Own Key) inline editor autocomplete via OpenAI-compatible APIs
- Dark neon hacker theme with monospace UI throughout
- Vim/terminal keybinding preset with Space-prefix chords
- Global ripgrep file search panel
- Settings window with models, agents, shortcuts, themes, and general config
- Onboarding wizard for first-run setup
- Auto-updater via Tauri updater plugin
